# **App Name**: QuranConnect

## Core Features:

- Course Listing & Details: Display a comprehensive list of available courses with detailed descriptions, objectives, and target audience information.
- Interactive Quran Reader: Allow users to read the full Quran online, chapter-by-chapter, with a visually appealing and easy-to-navigate interface.
- User Registration & Profile: Enable students to register for courses, manage their profiles, and track their progress.
- Certificate Generation: Automatically generate and issue certificates upon successful completion of courses.
- Personalized Learning Path: AI-powered tool that analyzes the student's current comprehension to customize learning paths and generate practice questions to optimize knowledge acquisition
- Tutor Availability: Display a schedule of available tutors.
- Contact Form: Allow prospective students to contact the admin to ask for specific information

## Style Guidelines:

- Primary color: Deep teal (#2A9D8F) to evoke trust, peace, and spiritual growth.
- Background color: Light teal (#E9F8F7) for a calm and serene backdrop.
- Accent color: Muted gold (#D4A373) to signify wisdom and tradition.
- Body font: 'PT Sans', a humanist sans-serif for modern readability.
- Headline font: 'Alegreya', a humanist serif, lends elegance.
- Use clear, intuitive icons to represent different courses and sections of the site.
- Design a clean, spacious layout that is easy to navigate on both desktop and mobile devices.
